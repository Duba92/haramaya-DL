# User Manuals

## Student

1. Register with your name, email, department, and a password with at least eight characters, one uppercase letter, and one number.
2. Sign in. Students land on their dashboard, which shows approved materials for their department and recent downloads.
3. Search by course code, title, or keyword. Narrow results by college, department, year, semester, course, and file type; sort by relevance, date, downloads, or title.
4. Alternatively, select **Browse** and expand the college, department, year, and semester to open a course.
5. Open a result to see its course and file details. Download buttons require sign-in and are available only for approved materials.
6. Select the bookmark control to save a material on the current browser/device. Browser storage must be enabled. Saved materials are not synchronized between devices or browsers.
7. While signed in, use **Report this material** to send a concern to the library administrator.

## Instructor

1. Register as an instructor and select your department. An administrator may also create or edit instructor accounts.
2. Sign in to open the instructor dashboard. It summarizes uploads, download counts, and pending reviews.
3. Select **Upload material**, enter a title and description, choose a course from your department, and select a PDF, DOCX, PPTX, or MP4 file within the configured size limit.
4. New uploads start in **Pending** status and are hidden from student search until approved.
5. Use **My uploads** to check review status and download counts. Edit metadata or delete an upload from this list.
6. Editing title or description returns the material to pending review. Deletion removes its database record and stored file.

## Administrator

1. Sign in with an administrator account. The dashboard shows user/material/download counts, uploads over time, downloads by department, and recent activity.
2. Open **Material review** to filter pending, approved, rejected, or all materials. Approve or reject individual items, or select multiple rows for a bulk action. Deletion removes the stored file and its related download/report records.
3. Open **Material reports** to mark reports open, resolved, or dismissed.
4. In **Users**, search by name/email and filter by role or activation state. Add and edit accounts, activate/deactivate accounts, reset a password, or delete an account. A reset password is displayed once in the admin session. Users with dependent uploads may need their materials reassigned or removed before deletion.
5. In **Courses**, add/edit the course code, title, department, year, semester, and assigned instructor. Deleting a course also deletes its materials and related history.
6. In **Colleges and departments**, add, rename, move, or delete curriculum records. Records still referenced by courses cannot be deleted.
7. In **Settings**, change the displayed site title/description, choose an image filename already present in `assets/images/`, set support email and allowed file types, lower the upload size limit, or enable maintenance mode.
8. Back up the database and uploaded files together. Store production backups outside the web root and test restoration regularly.
